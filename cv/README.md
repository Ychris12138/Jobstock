# cv/ 目录约定

> ⚠️ **这个目录里的文件永远不进 git（`README.md` 除外）。**
> CV 与解读文件含真实姓名、技能清单和「硬伤与短板」，本仓库是公开的，
> 推上去等同于公开发布，且会永久留在 git 历史里。`.gitignore` 已经用
> `cv/*` + `!cv/README.md` 挡住了，**不要用 `git add -f` 绕过它**。
> 每个人的 CV 只留在自己机器上；换机器请手动复制，不要靠 git 同步。

这里放两类文件：

1. **CV 原文**：任意格式（`.pdf` / `.md` / `.docx`），如 `cv-zh.md`、`cv-en.pdf`。
2. **CV 解读文件**：Markdown，命名为 `<名字>.reading.md`，如 `cv-zh.reading.md`。

解读文件不由系统自动生成：到 WebUI 的「CV 与解读」页复制提示词，
连同 CV 一起发给你的 AI agent，让它按下面的格式生成后保存回本目录。

## 解读文件格式（agent 必须遵守）

```markdown
# CV 解读：<名字>
## 目标方向
## 核心技能
## 偏好与约束
## 硬伤与短板
## 关键词
（恰好 10 个，顿号分隔，单独占一行 —— WebUI 会把这行提取成标签云）
## 匹配建议
```

只写 CV 里有据可查的内容，不要虚构。
